# Make Seven 7×7 Exact Solver

DF-PN v9.8.3による7×7 Make Sevenの厳密探索プログラムです。
1・2・3の駒は両プレイヤーとも枚数無制限。3は赤マスだけに置けます。
同色の連続した駒の合計がちょうど7になると勝ちです。
NNの重みや外部データベースなしで実行できます。

## 動作環境とビルド

Linux、またはWindows上のWSL/Ubuntuを使用します。GCC（C2x対応）、GNU Make、OpenMPが必要です。
Windowsの通常のコマンドプロンプトではなく、WSL/Ubuntuの端末で実行してください。
Ubuntuでビルドツールがない場合は `sudo apt update` と `sudo apt install build-essential` を実行します。

リポジトリをダウンロードし、`exact` フォルダで実行：

```bash
make
make test
```

ソースを利用者のマシンでコンパイルします。コンパイル済みバイナリは配布していません。

## 7×7の局面を解く

```bash
bash solve_7x7.sh "2A" 60
```

初手2Aを置いた局面を最大60秒探索します。位置表記は `駒の数字＋列A〜G` の連続です。
下から積み上げ、GREENが先手です。たとえば `2A1G2A1G2A1F` と指定します。
空盤面は `bash solve_7x7.sh "" 60`、時間無制限は秒数を `0` にします。
序盤の7×7は非常に難しく、時間内に解けないことがあります。

スクリプトは7×7、1スレッド、GREEN視点に固定しています。
探索用TTは256 MiB、共有TTは256 MiB、worker TTは64 MiBを要求し、
キャッシュ等が加わります。実際のメモリ使用量は環境・実行経路で異なります。
メモリを抑えるため追加のdeep-reroot探索とfrontier出力は無効にしています。

## 結果の読み方

最終の `Result` はGREEN視点です。
WINはGREEN勝ち、LOSSはGREEN負け、DRAWは引き分け、UNKNOWNは未解決です。
UNKNOWNを引き分け・敗北として扱わないでください。

出力は `exact/results/run-XXXXXXXX/` の `console.txt`、`progress.csv`、`summary.csv` に保存します。
開始時点で既に終局している場合などはCSVが生成されないことがあります。
終了コードは解決済みなら0、未解決なら4、入力エラー等は2または3です。

## 並列実行に関する既知の制約

提供済みのExact-Harvest v3.13.7には、v9.8.3で2/4スレッド実行時に
誤ったDISPROVEDが発生したという履歴（20試行中1回、1スレッドでは20/20正解）が記録されています。
この配布作業ではその不具合の再現・修正はしていません。
そのため同梱スクリプトは `--threads 1` を固定しています。
元のCプログラムには並列オプションが残っていますが、この配布版の案内では使用しません。
自己テストの合格は、全局面の正しさや7×7初期局面の完全解析を意味しません。

## ファイル

- `dfpn_solver_v9_8_3.c`：提供されたソースを変更せず収録。
- `Makefile`：ローカルビルドと自己テスト。
- `solve_7x7.sh`：7×7・1スレッド用の実行スクリプト。
- `SOURCE_INFO.json`：出典とSHA-256。
- `VERIFICATION.txt`：今回の動作確認記録。

以前の5×7/2Cキャンペーン用起動スクリプト・DB・マシン固有パスは含めていません。
近似solverはリポジトリ最上位に配置し、このフォルダをその下の `exact/` として追加できます。
